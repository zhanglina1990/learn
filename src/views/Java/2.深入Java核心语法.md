# 面向对象基础
## 类
一种抽象的数据类型，是对一类具有相同属性和方法的对象的抽象。
// 定义一个Person类
```java
public class Person {
    // 属性：姓名、年龄
    String name;
    int age;

    // 方法：吃饭、睡觉
    void eat() {
        System.out.println("正在吃饭");
    }
    void sleep() {
        System.out.println("正在睡觉");
    }
}
```


## 对象
对象是类的实例，通过对象可以访问类中定义的属性和方法。
```java
// 创建Person对象
public class Main {
    public static void main(String[] args) {
        Person person1 = new Person();
        person1.name = "张三";
        person1.age = 18;
        person1.eat();
        person1.sleep();
    }
}
```
上述代码中person1是Person类的一个实例对象。通过person1可以访问Person类中定义的属性和方法。

> 注意：在Java中，类名和对象名的首字母通常是大写的。

# 方法重载
方法重载是指在同一个类中可以定义多个同名的方法，只要它们的参数列表不同即可。

练习
1. 定义一个Circle类，包含半径radius属性和计算圆面积和周长的方法
```java
public class Circle {
    double radius;
    
    double calculateArea() {
        return Math.PI * radius * radius;
    }
    
    double calculateCircumference() {
        return 2 * Math.PI * radius;
    }
}
```
